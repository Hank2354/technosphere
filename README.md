# ТехноСфера

ТехноСфера — учебный веб-сервис для сопровождения оформления документов на продукцию. Клиент подаёт заявку, менеджер координирует её обработку, специалист определяет необходимые документы и оформляет их после оплаты, а отдел доставки отправляет готовые документы.

Проект разрабатывается для практикума №1–4 по дисциплине «Коллективная разработка приложений».

## Участники процесса

| Роль | Тип сотрудника | Основные действия |
|---|---|---|
| Пользователь | — | Создание заявок, ответы на уточнения, согласование стоимости, получение счёта, отслеживание выполнения |
| Сотрудник | Менеджер | Проверка заявок, общение с клиентом, передача специалистам, определение стоимости, выставление счёта, подтверждение оплаты |
| Сотрудник | Специалист | Анализ продукции, заключение о необходимых документах, оформление и загрузка готовых документов |
| Сотрудник | Доставка | Получение готовых заказов, отправка документов, указание трек-номера и завершение доставки |

## Основной сценарий

1. Клиент регистрируется и отправляет заявку с описанием продукции и кодом ТН ВЭД.
2. Менеджер проверяет заявку и при необходимости запрашивает уточнения.
3. Специалист берёт заявку на анализ и указывает необходимые документы.
4. Менеджер определяет стоимость, клиент согласует её.
5. Менеджер выставляет счёт и после поступления денег подтверждает оплату.
6. Специалист оформляет документы и прикрепляет результат к заявке.
7. Отдел доставки отправляет документы и фиксирует результат доставки.

## Первая версия

- Регистрация клиентов и вход в систему.
- Две роли и три типа сотрудников с различными правами.
- Заявки, комментарии, вложения и история изменения статусов.
- Анализ продукции и заключение специалиста.
- Согласование стоимости и счёт в виде прикреплённого файла.
- Подтверждение оплаты менеджером.
- Загрузка оформленных документов.
- Учёт доставки и трек-номера.

## Учебные требования

MVC, разделение ответственности, доступ к базе данных через Repository, асинхронные операции, обмен данными в JSON, автоматизированные тесты, проверка входных данных и прав доступа. Разработка ведётся в GitHub с задачами, ветками и pull request.
